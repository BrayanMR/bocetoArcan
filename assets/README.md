# ARCA - Frontend Prototype

Plataforma de streaming para emisoras de radio, audio y contenido en vivo.

## Estructura del proyecto
- `index.html`: Estructura principal semántica.
- `css/styles.css`: Sistema de diseño, CSS grid/flexbox, variables y animaciones.
- `js/app.js`: Lógica vanilla ES6+, reproductor interactivo, visualizador de audio Canvas, temas y datos mock.
- `assets/`: Recursos y documentación del proyecto.

## Ejecución
Abre `index.html` directamente en cualquier navegador moderno.
